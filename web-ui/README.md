# Веб-интерфейс APEX Discord Snapshot Master

Просмотрщик открывается на английском. Русский можно выбрать в меню **Language** на боковой панели.

Просмотрщик открывает историю каналов и веток из `snapshot.sqlite`, включая реакции со счётчиками. Поиск работает по тексту сообщений выбранного канала. Скачанные вложения, аватары, пользовательские эмодзи и поддерживаемые медиа открываются из `media/`. Стандартные эмодзи используют Discord Twemoji. Сведения о лицензии находятся в `Twemoji-NOTICE.txt`. Значок солнца или луны переключает тему.

## Локальный запуск

Из папки `web-ui` запустите с Python 3.10 или новее. Дополнительные пакеты не требуются.

```sh
python server.py
```

Откройте [http://127.0.0.1:8080](http://127.0.0.1:8080). По умолчанию сервер читает архив из родительской папки. Если импорт ещё удерживает SQLite, поставьте его на паузу и повторите запрос.

## Docker

Из корня архива запустите контейнер с помощью `compose.yml`. Compose подтягивает актуальный тег `latest` и открывает просмотрщик по адресу [http://127.0.0.1:8080](http://127.0.0.1:8080).

```sh
docker compose up -d
```

Для локальной сборки из папки `web-ui/` в архиве выполните из его корня следующие команды.

```sh
docker build -t discord-snapshot-web ./web-ui
docker run --rm -p 127.0.0.1:8080:8080 --mount "type=bind,source=$PWD,target=/archive" discord-snapshot-web
```

При выключенной авторизации история и вложения доступны каждому, кто может обратиться к серверу. При удалённом развёртывании используйте обратный прокси с HTTPS и передавайте исходный заголовок Host. Для архива с Discord OAuth2 публичный адрес должен совпадать с Redirect URI без пути `/auth/callback`. Для архива без OAuth2 укажите домен через `--allow-host archive.example.org` после имени образа. Исключите параметры OAuth2 callback-запросов из журнала прокси.

Контейнер по умолчанию работает от UID/GID 65534. Для администрирования внутри архива на Linux этому пользователю нужна запись в `snapshot.sqlite` и его каталог. UID и GID можно задать с помощью `DISCORD_ARCHIVE_UID` и `DISCORD_ARCHIVE_GID`. Для развёртывания только для чтения задайте `DISCORD_ARCHIVE_READ_ONLY=true`.

При включённой авторизации наличие `.discord-auth.json` закрывает API и вложения до входа через Discord. Client Secret хранится в этом файле, поэтому права на каталог архива должны разрешать чтение только владельцу и процессу просмотрщика. Сеанс действует до одного часа. Изменение настроек OAuth2 аннулирует существующие сеансы.

Через **Управление доступом** администратор может добавлять и удалять пользователей и гильдии. Список должен содержать хотя бы одного администратора. Изменения применяются к запросам с уже активными сеансами. Администратор также может ограничить доступ ко всему архиву, скрывать каналы с дочерними ветками и показывать их снова. Вложения из скрытого канала доступны обычным пользователям, если на них также ссылается видимый канал.

Удаление убирает записи канала, сообщений, дочерних веток и ссылки на их уникальные вложения из SQLite. Общие вложения остаются доступны там, где используются. Файлы вложений остаются на диске.
